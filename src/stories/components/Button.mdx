# Button

Space Mono, ALL CAPS, wide-tracked — reads as a terminal command. Three variants cover every action context in the system. Labels are rendered exactly as provided; capitalize in the prop string.

## Variants

### Primary

The single committed action on a surface. Phosphor green text on deep-green fill.

<Canvas of={ButtonStories.Primary} />

_Canonical use: `ASK` (chat submit), `COMPOSE EMAIL +` and `OPEN PROFILE +` (Contact page). One primary per surface._

### Secondary

Available but not the recommended next step. Always paired with a primary nearby.

<Canvas of={ButtonStories.Secondary} />

_Canonical labels: `COPY ADDRESS`, `COPY URL`. Always paired with a primary — never the only button on a surface._

### Ghost

Optional navigation-adjacent action. No fill, no border — reduced visual weight.

<Canvas of={ButtonStories.Ghost} />

### Disabled / Loading

The ASK button disables when the input is empty, and while a response is in-flight.

<Canvas of={ButtonStories.Disabled} />

_The empty-input ASK button is the only unconditional disabled use. Prefer hiding over disabling in other contexts._

## Do's

- **One primary per surface.** Two primaries side by side create visual ambiguity.
- **Short ALL CAPS commands.** `ASK`, `COMPOSE EMAIL +`, `COPY ADDRESS`, `OPEN PROFILE +`.
- **Pair secondary with a primary.** A secondary standing alone has no anchor.
- **Ghost for optional choices.** Back, More, View — actions that shouldn't compete.

## Don'ts

- **Don't invent a fourth variant.** Primary / secondary / ghost cover every case.
- **Don't use Button for navigation.** Use an `<a>` tag or pass `href` to render as an anchor.
- **Don't use sentence-case labels.** The component renders text as-is — capitalize in the prop.

## Size

`md` is the only size in production. `sm` and `lg` exist for future contexts.

## AI guidance

Space Mono, all-caps, wide-tracked — reads as a terminal command. Three variants cover every action context. Never invent a fourth variant; never use sentence-case labels.

**Content rules**
- All button text is ALL CAPS — the component renders text as provided; capitalize in the prop.
- Canonical labels: `ASK` (chat submit), `VIEW CASE STUDY +`, `COMPOSE EMAIL +`, `OPEN PROFILE +` (Contact), `COPY ADDRESS`, `COPY URL` (secondary actions).
- One primary button per surface maximum.

**Avoid**
- Don't invent a new Button variant — primary, secondary, ghost cover every case.
- Don't use Button for navigation links — use an `<a>` tag or pass `href` to render as anchor.
- Don't show a spinner inside the button or change the label to `Loading...` while in-flight — the ChatInput sweep animation is the loading affordance.
