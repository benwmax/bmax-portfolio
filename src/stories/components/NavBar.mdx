# NavBar

Site header — wordmark left; About, Resume, Contact, and Design system ↗ right. Present on every page. Transparent: sits directly on the page background with only a 1px bottom rule. Wire `activePath` to the router pathname to mark the active link.

The `BM_` wordmark with its trailing underscore is a terminal cursor convention — do not modify the wordmark. The underscore is static (it stopped blinking 2026-10-29); don't add the animation back.

The Retro/Futuristic switch at the right edge is a separate documented component — see [ThemeToggle](/docs/components-themetoggle--docs) for its own states and guidance. NavBar's `Futuristic V2` story below renders it live.

## Do's

- **Wire `activePath` to the current router pathname** on every page.
- **Use the fixed links:** About `/about`, Resume `/resume`, Contact `/contact`, and Design system (`system.viewbens.work`, opens in a new tab). The wordmark is the way home.

## Don'ts

- **Don't leave `activePath` undefined in production.** All links render at disabled-text when no route matches.
- **Don't add nav links or dropdown menus.** Four links fit at 360px only because of the short label and the compact theme switch.
- **Don't add a mobile hamburger.** The nav is intentionally always visible.
