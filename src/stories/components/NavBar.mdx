# NavBar

Site header — wordmark left, three nav links right. Present on every page. Transparent: sits directly on the page background with only a 1px bottom rule. Wire `activePath` to the router pathname to mark the active link.

The `BM_` wordmark with blinking underscore is a terminal cursor convention — do not modify the wordmark or remove the blink.

## Do's

- **Wire `activePath` to the current router pathname** on every page.
- **Use the three fixed links:** Work `/work`, About `/about`, Contact `/contact`.

## Don'ts

- **Don't leave `activePath` undefined in production.** All links render at disabled-text when no route matches.
- **Don't add nav links or dropdown menus.** Three links fit at 390px without collapsing.
- **Don't add a mobile hamburger.** The nav is intentionally always visible.
