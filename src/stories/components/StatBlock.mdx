# StatBlock

Outcome stat cell — headline value in phosphor green at display weight, short label in ALL CAPS, optional one-line context body. The value is what the eye lands on first. Always use `StatGrid` to compose multiple cells — the grid technique (background: border-subtle, gap: 1px) produces hairline dividers without doubling borders.

## Value vocabulary

| Type | Examples |
|------|---------|
| Percentage | `+4–6%`, `+23%` |
| Currency | `$1B`, `$800M` |
| Time | `< 3 mo.` |
| Direction | `↓ Calls` |
| Qualitative | `Scaled`, `Shipped`, `Adopted`, `Launched` |

## Do's

- **Always use `StatGrid` wrapper.** Never lay out cells manually.
- **Use concrete values.** `+4–6%` not "Improved significantly."
- **Omit `body` when the value is self-explanatory.** `$1B` with "Contract won" needs no body.
- **Label in ALL CAPS.** "Conversion lift · P&C", "Contract won".

## Don'ts

- **Don't use vague qualifiers as values.** "Improved", "Better", "Enhanced" are not values.
- **Don't force a body sentence** if the value already tells the story.
- **Don't use `cols={3}` for 2 cells.** Use the default 2-col grid.

## AI guidance

Outcome stat cell — phosphor green headline value, ALL CAPS label, optional context body. Always use `StatGrid` wrapper for multiple cells. Never lay out cells manually.

**Content rules**
- `value`: concrete number or short word — `"+4–6%"`, `"$1B"`, `"< 3 mo."`, `"↓ Calls"`, `"Scaled"`, `"Shipped"`, `"Adopted"`.
- `label`: ALL CAPS descriptor — `"Conversion lift · P&C"`, `"Contract won"`, `"Mobile redesign ship"`.
- `body`: one sentence of context — `"Homeowners up 5%."` Keep it short. Omit when the value is self-explanatory.
- `StatGrid` default (2-col) holds 2 or 4 cells. Use `cols={3}` for exactly 3 stats.
- Always use `StatGrid` wrapper — never lay out cells manually.

**Avoid**
- Don't use vague qualifiers as values: `"Improved"`, `"Better"`, `"Enhanced"`.
- Don't force a body sentence if the value already tells the story.
- Don't lay out StatBlock cells without StatGrid.
- Don't use `cols={3}` for 2 cells — use the default 2-col grid.
